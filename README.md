Google is the parent of the Google API estate, publishing public APIs across Google Cloud (compute, data, AI and the Apigee API platform), Google Workspace (Gmail, Drive, Docs, Calendar, Meet), Maps, YouTube, Ads, Analytics, Firebase and Android. Its APIs are documented at developers.google.com and described machine-readably through the Google APIs Discovery Service.

**Areas:** Advertising · Cloud · Developers · Google · Platform · Search · T1 · Agentic Commerce · Universal Commerce Protocol · AP2 · A2A

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Google: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
